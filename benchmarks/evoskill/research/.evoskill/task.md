# Task
Improve the research-evidence skill for evidence-based research about software, AI and Web3 projects.

## Requirements
- Prefer primary sources and record source dates.
- Separate verified facts, assumptions, unknowns and conflicts.
- Never invent citations, URLs, metrics or launch status.
- Do not treat a search failure as evidence that a claim is false.
- Keep the final answer concise, sourced and explicit about uncertainty.

Optimize skills only. Do not modify application code or execute arbitrary commands.
