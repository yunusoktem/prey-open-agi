# Web3 protocol analysis skill

- Verify project identity and official domains before attributing repositories, announcements or contracts.
- Separate testnet, devnet, mainnet, beta, announced and generally available product status.
- Verify chain/network and token contract before discussing a token or market listing.
- Distinguish total supply, circulating supply, unlocked supply, emissions and vesting.
- Treat exchange listings, partnerships, integrations, audits and funding as claims requiring dated evidence.
- Use repository activity as one signal only; inspect releases, contributors, issue history and license.
- Explain material risks and missing evidence. Never fabricate prices or provide personalized investment instructions.
