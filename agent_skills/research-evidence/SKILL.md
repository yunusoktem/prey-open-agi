# Research evidence skill

- Translate the request into a small set of answerable questions before researching.
- Prefer primary sources: official documentation, repositories, releases, governance records and audited disclosures.
- Check publication dates and distinguish current facts from historical statements.
- Cross-check material claims with independent sources where possible.
- Keep each claim tied to the source that supports it; never invent URLs, quotations, metrics or citations.
- Label findings as verified, partially verified, not found or conflicting.
- A failed search is not evidence that a fact is false. State when sources are unavailable.
- Separate facts, interpretation and uncertainty. Do not turn speculation into a conclusion.
